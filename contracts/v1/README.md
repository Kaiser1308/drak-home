# DRAK contract v1 (prerelease)
JSON Schema Draft 2020-12 structural schemas. See docs/03 and docs/04 for semantics. All payloads are examples, not observed device output. `artifact_hash` in deployment examples is SHA-256 over exact bytes of `examples/artifact.json` (including newline); the final serialization/hash agreement for embedding artifact objects on wire is an M0 open decision. Do not use examples as real authorization. Schema validates only shape; independently validate embedded artifact, units, ranges, sizes, reference identity, runtime support, owner, auth, and replay. `details` event payload remains open pending event taxonomy. Timer trigger is provisional. Schemas intentionally do not define implementation or guarantee safety.

Conformance vectors use virtual milliseconds, normalized milli-Celsius, initial fan off unless stated. No runner included. Test events are interpreted in order; evaluate due deadlines after input events at same tick. Fixtures do not cover all failure modes. Hardware evidence requires real tests.
